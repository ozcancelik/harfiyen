# Yazı tipleri

Altyazılı videoda libass'ın kullandığı yazı tipleri, web uygulamasındaki on yazı tipiyle aynı. Hepsi Türkçe
karakterlerin tamamını içerir. Lisansları `licenses/` altında; hepsi serbest dağıtıma izin verir (SIL OFL,
Luckiest Guy için Apache 2.0).

Montserrat, Inter, Schibsted Grotesk, Literata ve Google Sans Flex değişken yazı tipleridir; libass değişken
eksenleri seçemediği için Bold (700) örnekleri sabit TTF olarak üretildi (`fontTools.varLib.instancer`).
Anton, Bebas Neue, Bangers ve Luckiest Guy tek kalınlıklıdır.
